# 🛡️ Data Protection & Privacy Statement (GDPR / Privacy Shield)

**Project:** BumpArena 2D  
**Effective Date:** 2026  
**Status:** Non-commercial, open-source peer-to-peer hobby project.

To ensure transparency and alignment with European data regulations (GDPR), we declare the following regarding **BumpArena 2D**:

1. **Zero Personal Data Collection:** This game does **not** collect, store, process, or transmit any personal data (such as names, email addresses, IP addresses for tracking, phone numbers, or physical locations).
2. **Peer-to-Peer (P2P) Architecture:** Multiplayer connections are established directly between players' devices via WebRTC. A lightweight signaling server (PeerJS) is used solely to initially handshake and pair the peers; it does not log, record, or store gameplay history or user communications.
3. **No Cookies or Tracking:** The application uses no tracking cookies, analytics scripts (such as Google Analytics), or third-party marketing trackers. Any minor preference states (if any) are kept strictly within your browser's local sandbox storage (`localStorage`) and never leave your machine.
4. **Exemption Note:** As this project is a static, non-monetized, open-source hobbyist browser game that does not process user profiles or commercial transactions, it operates with minimal compliance overhead while fully respecting user privacy.
