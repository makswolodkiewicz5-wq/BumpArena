\# 💻 Hardware Requirements – BumpArena 2D



Since \*\*BumpArena 2D\*\* is built entirely using pure HTML5 and Canvas technology, its system requirements are minimal.



\### 🟢 Minimum Requirements:

\- \*\*Processor:\*\* Any dual-core CPU clocked at 1.6 GHz or higher.

\- \*\*RAM:\*\* 1 GB RAM (2 GB recommended).

\- \*\*Graphics:\*\* Integrated graphics with hardware 2D acceleration support in the browser.

\- \*\*Web Browser:\*\* Any modern web browser with HTML5 / WebGL / WebRTC support (Google Chrome, Mozilla Firefox, Microsoft Edge, Opera, or Safari in recent versions).

\- \*\*Network:\*\* Stable internet connection for online multiplayer (local router is sufficient for LAN play).



\### 🚀 Recommended:

\- \*\*Browser:\*\* Latest version of Google Chrome or Mozilla Firefox.

\- \*\*Display:\*\* Minimum resolution of 1280x720 pixels.

\- \*\*Input Devices:\*\* Keyboard (or two separate control schemes for local co-op).
